## Descripción del Proyecto

GaMa es un sistema integral diseñado para la administración operativa y financiera de una empresa de camiones utilitarios orientada al transporte de materiales de construcción. 

El sistema centraliza la gestión de unidades, conductores, contratos y hojas de ruta, permitiendo el cálculo automatizado de costos operativos, consumos y mantenimientos preventivos/correctivos, además de proveer un panel de control con métricas clave para la toma de decisiones gerenciales.
